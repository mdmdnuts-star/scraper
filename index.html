AWS CloudFront

Global edge network providing low latency caching, SSL termination, and basic DDoS protection for incoming requests.

Key Specs:
  • Cache Hit Ratio: ~98.4%
  • Global Locations: 400+ Edge Locations
  • Security: AWS WAF integrated
Infrastructure as Code (Terraform): 
resource "aws_cloudfront_distribution" "cdn" {
  origin {
    domain_name = aws_api_gateway_rest_api.api.id
    origin_id   = "APIGatewayOrigin"
  }
  enabled             = true
  is_ipv6_enabled     = true
  default_root_object = "index.html"
}
